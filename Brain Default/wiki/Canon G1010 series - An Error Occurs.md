# Canon G1010 series: An Error Occurs

Nguồn chính hãng Canon về support code tương ứng với số lần nháy đèn Alarm hoặc kiểu nháy luân phiên của ON và Alarm trên G1010 series. [Canon G1010 series: An Error Occurs](https://ij.manual.canon/ij/webmanual/Manual/All/G1010%20series/EN/NTR/ntr_t_07_01_c.html/ntr_t_07_02.html)

- Alarm nháy 5 lần: support code 1403, 1430, 1471 hoặc 1476. [[Canon G1010 - mã nháy đèn]]
- ON và Alarm nháy luân phiên 5 lần: support code 5700. [[Canon G1010 - mã nháy đèn]]
