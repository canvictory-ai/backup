# Epson ET-2800 series: mã hiển thị lỗi

Bảng dưới đây lấy từ User's Guide Epson dùng chung ET-2800/ET-2803. Đây là mã hiển thị trên LCD cho người dùng, không phải mã service nội bộ. [[Epson ET-2800 ET-2803 User Guide error codes]]

- **E-01:** lỗi máy in. Epson hướng dẫn tắt/bật lại; nếu còn, kiểm tra kẹt giấy, sau đó liên hệ hỗ trợ. [[Epson ET-2800 ET-2803 User Guide error codes]]
- **E-02:** lỗi scanner; tài liệu hướng dẫn tắt/bật lại. [[Epson ET-2800 ET-2803 User Guide error codes]]
- **E-11 / E-12:** ink pad cần thay / ink pad in tràn lề cần thay; liên hệ Epson. Với E-12, in tràn lề không khả dụng. [[Epson ET-2800 ET-2803 User Guide error codes]]
- **W-01:** kẹt giấy. [[Epson ET-2800 ET-2803 User Guide error codes]]
- **W-11 / W-14:** ink pad thường / ink pad in tràn lề gần hết tuổi thọ. [[Epson ET-2800 ET-2803 User Guide error codes]]
- **I-22:** hướng dẫn thiết lập Wi-Fi bằng nút router/access point hoặc giao diện cài đặt trên máy tính. [[Epson ET-2800 ET-2803 User Guide error codes]]
