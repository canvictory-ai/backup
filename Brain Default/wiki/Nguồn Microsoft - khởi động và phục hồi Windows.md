# Nguồn Microsoft - khởi động và phục hồi Windows

- Microsoft Support, [Windows Startup Settings](https://support.microsoft.com/en-us/windows/experience/startup-boot/windows-startup-settings), truy cập 24/11/2026. Hướng dẫn vào Safe Mode qua Windows Recovery Environment và dùng Safe Mode để khoanh vùng driver/dịch vụ.
- Microsoft Support, [Startup Repair](https://support.microsoft.com/en-us/windows/experience/startup-boot/startup-repair), truy cập 24/11/2026. Hướng dẫn dùng Startup Repair cho một số lỗi ngăn Windows khởi động; cần khóa BitLocker nếu thiết bị mã hóa.
- Microsoft Support, [Recovery options in Windows](https://support.microsoft.com/en-us/windows/experience/backup-recovery/recovery-options-in-windows), truy cập 24/11/2026. Cảnh báo một số tùy chọn phục hồi có thể làm mất dữ liệu và khuyến nghị sao lưu trước.

[[Lỗi máy tính để bàn có nguồn nhưng không lên hình]] dùng các trang này khi máy đã qua POST và biểu hiện lỗi thuộc Windows/khởi động; chúng không chẩn đoán phần cứng.
