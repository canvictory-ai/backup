# Tài liệu hãng về lỗi cơ bản hệ thống mạng

Microsoft phân biệt trạng thái không có kết nối vật lý, vấn đề TCP/IP/gateway và lỗi phân giải DNS; Cisco mô tả lỗi cấu hình IP, DHCP, lớp vật lý, địa chỉ IP trùng, định tuyến và DNS. Microsoft cũng chia sự cố Wi-Fi thành lỗi kết nối/xác thực, mất truy cập dù vẫn kết nối, rớt kết nối/roaming và lỗi sau cập nhật hoặc sleep. Đây là nhóm phân loại, chưa phải chẩn đoán cho một mạng cụ thể. [Microsoft: TCP/IP](https://learn.microsoft.com/en-us/troubleshoot/windows-server/networking/troubleshoot-tcp-ip-communication-guidance) · [Microsoft: DNS client](https://learn.microsoft.com/en-us/troubleshoot/dns/troubleshoot/troubleshoot-dns-client) · [Microsoft: Wi-Fi](https://learn.microsoft.com/en-us/troubleshoot/windows-client/networking/wireless-network-connectivity-issues-troubleshooting) · [Cisco: TCP/IP troubleshooting](https://www.cisco.com/en/US/docs/internetworking/troubleshooting/guide/tr1907.html)
